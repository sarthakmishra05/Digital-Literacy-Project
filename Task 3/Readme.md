Digital Literacy Awareness Quiz 🌐
A streamlined, 5-question assessment tool built with Google Forms to evaluate and improve digital literacy among students. This project focuses on identifying gaps in online security knowledge, misinformation detection, and data privacy.

🚀 Purpose
In an era of rapid digital transformation, being "online" isn't the same as being "digitally literate." This quiz serves as a quick diagnostic tool for my batchmates to test their ability to navigate the web safely, critically, and ethically.

📊 Quiz Content
The assessment covers five core pillars of digital citizenship:

Phishing Awareness: Identifying suspicious communication and malicious links.

Critical Thinking: Evaluating the credibility of online information sources.

Account Security: Understanding the importance and mechanics of Two-Factor Authentication (2FA).

Privacy Controls: Self-assessment of privacy setting management.

Digital Economy: Understanding the "Data-for-Service" model of modern apps.

🛠️ Tools Used
Google Forms: Platform for survey creation and data collection.

Google Sheets: Backend data management for real-time response analysis.

📝 How to Use
Access the Form: https://docs.google.com/forms/d/e/1FAIpQLSdcG4s-bzc3yUh-pbGiQmlzI6IuL8TYojafJQagmf-bJz705g/viewform?usp=publish-editor

Submit Responses: Users answer 5 varied questions (Multiple Choice, Short Answer, Linear Scale).

Review Feedback: Automated feedback is provided upon submission to turn the quiz into a learning opportunity.

💡 Impact
This project aims to foster a more "cyber-aware" student community, reducing the risk of data breaches and the spread of misinformation within the batch.
